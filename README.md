Explainable AI for Intrusion Detection (XAI-IDS)
Project Description

This project builds a Machine Learning-based Intrusion Detection System (IDS) using the UNSW-NB15 dataset.
It also applies Explainable AI (XAI) techniques such as SHAP and LIME to interpret model predictions.

Features
Data preprocessing and feature engineering
Machine learning classification model
Explainability using SHAP / LIME
Performance evaluation using standard metrics

Dataset
UNSW-NB15 Dataset (Kaggle)

Tools & Libraries
Python
Pandas
NumPy
Scikit-learn
Matplotlib
SHAP
LIME
Joblib

How to Run
Option 1: Run Locally
Clone the repository:
git clone https://github.com/your-username/xai-intrusion-detection.git
cd xai-intrusion-detection
Install dependencies:
pip install -r requirements.txt
Run Jupyter Notebook:
jupyter notebook
Open the notebook file and run all cells.
Option 2: Run on Google Colab
Open the notebook file (.ipynb)
Upload it to Google Colab
